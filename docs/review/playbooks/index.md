# Playbooks

* [Review a pull request](review_a_pull_request.md) - Stage-1 agent routing table and procedure for loading compact subsystem rules under `docs/review/rules/` without reading `docs/review_playbook.md` or `docs/review/provenance.json`.
* [Prepare a pull request](prepare_a_pull_request.md) - Pre-submission author workflow for self-checking diffs against targeted review rules and running `make presubmit`.
* [Maintain the review knowledge bundle](maintain_review_bundle.md) - Two-stage maintenance workflow covering `rules/*.md` + `provenance.json` updates, compiling `docs/review_playbook.md`, settling open questions, and `--check-staleness` audits.
