# Playbooks

* [Review a pull request](review_a_pull_request.md) - Two-pass additive review procedure and Stage-1 diff-path routing table (`0` to `2` rule files per diff) without reading `docs/review_playbook.md` or `docs/review/provenance.json`.
* [Prepare a pull request](prepare_a_pull_request.md) - Pre-submission author workflow for self-checking diffs against code search, targeted review rules, and `make presubmit`.
* [Maintain the review knowledge bundle](maintain_review_bundle.md) - Two-stage maintenance workflow covering `rules/*.md` + `provenance.json` updates, compiling `docs/review_playbook.md`, settling open questions, and `--check-staleness` audits.
