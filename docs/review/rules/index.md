# Review Rules

Compact Stage-1 non-code review rules loaded selectively in Pass 2 via [review_a_pull_request.md](../playbooks/review_a_pull_request.md) after full-repo code inspection and [AGENTS.md](../../../AGENTS.md). Citation provenance, recurrence counts, and rationale live in [`provenance.json`](../provenance.json) and compile into [`docs/review_playbook.md`](../../review_playbook.md) for human readers.

* [External wire and engine contracts](external_wire_and_engine_contracts.md) - Anthropic split prompt tokens, vLLM `continuous_usage_stats`, untouched JSON/`Content-Length`/RFC 9110 `Connection: upgrade` fidelity and client `Accept-Encoding`, native engine `/render` passthrough and stateful `/v1/responses` rejection, router-built P/D `kv_transfer_params`, and ZMQ KV-event sequence recovery.
* [Unencoded runtime hazards](unencoded_runtime_hazards.md) - Unjoined timed-out `DataProducer` goroutines vs request mutation and `sync.Pool` buffers, Envoy `ext_proc` early header-skip metrics and decode-pod filtering, SSE chunk-boundary carry and last-usage folding with `ResponseWriter.Unwrap()`, `(host, port, rank)` endpoint keys, bounded metric labels and series cleanup, and no locks held across network calls.
* [Governance and compatibility policy](governance_and_compatibility_policy.md) - `N+2` deprecation for shipped surfaces vs zero shims for unshipped surfaces, `Alpha`/`Beta`/`Stable` plugin graduation and frozen `stable/v1/` fixtures, unmerged upstream engine gates and versioned GIE CRDs, and `config/charts/` Helm vs `test/e2e/artifacts/` Kustomize.
* [Settled architectural boundaries](settled_architectural_boundaries.md) - Capacity shedding in `SaturationDetector`/`AdmissionPlugin`, single base model and role per `InferencePool` (`models-responder` exception), external conversation history vs bounded routing state, `pkg/coordinator` vs `pkg/sidecar`, and ingress-only header stripping at every client entry point.
