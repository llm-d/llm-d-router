# Decisions

Settled architectural tradeoffs from maintainer review threads and maintainer policy decisions.

* [Prefix-cache block size parameter includes Tokens unit suffix](prefix_cache_block_size_tokens_unit_suffix.md) - Prefix-cache scorer configuration names the block-size field blockSizeTokens rather than unitless blockSize.
* [Session affinity as a shared stateless helper package](session_affinity_shared_helper.md) - Lightweight session-affinity header parsing lives in a shared helper package under pkg/epp/framework/plugins/scheduling/util/sessionaffinity rather than a mandatory DataProducer plugin.
* [Typed data-layer Slot handles over generic Extractor interfaces](typed_datalayer_slots_over_generic_extractors.md) - Cross-plugin data-layer typing uses typed Slot[T] and DataKey handles while keeping extractor interfaces non-generic.
* [Unified llm-d-router repository housing EPP, Coordinator, and disagg sidecar](unified_llm_d_router_monorepo.md) - Endpoint Picker, Coordinator, and disaggregation sidecar ship from the single llm-d-router repository rather than split per-binary repositories.
* [Organization-prefixed container image names](org_prefixed_container_image_names.md) - Published container images retain the llm-d-router-* prefix under ghcr.io/llm-d for organization-wide consistency.
* [Core endpoint identity on EndpointMetadata and optional topology in AttributeMap](endpoint_identity_metadata_vs_optional_attributes.md) - Core identity fields live on EndpointMetadata while optional per-endpoint properties such as worker rank flow through datalayer AttributeMap.
* [Scorer-internal fallback over scheduler fallback profiles](scorer_internal_fallback_over_fallback_profiles.md) - Missing telemetry fallbacks are handled inside individual scorers rather than adding multi-profile fallback chains to the core scheduler.
* [Helm charts for end-user releases and deploy Kustomize manifests for local kind and E2E](helm_release_charts_with_dev_kustomize_manifests.md) - End-user deployments ship through config/charts Helm charts while Kustomize overlays under deploy remain scoped to local development and E2E suites.
* [Channel-fed maintenance loop with lock protection for dynamic priority bands](channel_fed_priority_band_reconciliation.md) - Dynamic InferenceObjective priority bands provision off the hot path via edge-triggered controller reconciliation feeding a lock-protected processor loop.
* [Two-release deprecation shims required even during pre-1.0 config refactors](two_release_deprecation_shims_for_pre_v1_config.md) - Shipped user-facing configuration formats preserve backward-compatible deprecation shims for two releases rather than breaking operators across API graduations.
* [Delete stranded deprecation helpers in the removal pull request](delete_stranded_deprecation_helpers_immediately.md) - Unreferenced registration and compatibility helpers are deleted in the pull request that removes their last caller rather than retained for hypothetical reuse.
* [Upstream producer signal extraction without deep cross-API AST translation](producer_signal_extraction_with_raw_render_passthrough.md) - token-producer extracts scheduling signals into request attributes while forwarding raw client payloads directly to engine render endpoints.
* [Native engine render endpoints preferred over router-side API translation](native_engine_render_endpoints_over_schema_translation.md) - New inference API integrations target native engine /render routes directly, allowing contained interim translation only while native engine endpoints land.
* [Token count estimation encapsulated inside token-producer](encapsulate_token_estimation_in_token_producer.md) - Fast byte-length and tokenized prompt estimates live inside token-producer rather than as methods on core InferenceRequest types.
* [Pre-admission header attribute extraction via dedicated plugin extension point](request_header_extractor_before_admission.md) - Caller identity headers are extracted into request attributes before flow-control admission via RequestHeaderExtractor plugins rather than PreAdmission hooks.
* [Per-request endpoint attribute isolation with dynamic metric read-through](per_request_endpoint_attribute_isolation_with_dynamic_readthrough.md) - Scheduling snapshots isolate per-request endpoint attributes such as prefix-match scores while reading live shared metrics dynamically.
* [Component metrics reference in llm-d-router paired with user guides in llm-d/llm-d](local_metrics_docs_paired_with_umbrella_user_guides.md) - llm-d-router maintains code-synchronized component metrics docs and dashboards while user-facing multi-component guides update llm-d/llm-d.
* [E2E suites test locally built :dev images and third-party images pin explicit versions](local_dev_images_in_e2e_and_pinned_third_party_tags.md) - Pull request E2E workflows build and run local :dev images rather than floating :main tags, and third-party container images pin immutable version tags.
* [Disaggregation sidecar serves /metrics on its existing HTTP listener mux](sidecar_metrics_on_shared_http_mux.md) - The disaggregation sidecar exposes Prometheus /metrics on its existing HTTP mux rather than opening a second metrics port, while gRPC-based EPP keeps a dedicated metrics port.
* [Ratio-sampled per-plugin OpenTelemetry spans with high-overhead KV-event spans gated off](sampled_per_plugin_otel_spans_and_opt_in_kv_event_spans.md) - Request-path filter and scorer OpenTelemetry spans run under ratio sampling while high-overhead per-KV-event spans remain off by default.
* [Pool-wide /v1/models aggregation via generic Responder plugin interface](models_responder_generic_extension_point.md) - EPP answers GET /v1/models through the optional models-responder plugin behind a generic Responder interface without coupling core runtime packages to concrete plugins.
* [Flow control remains opt-in by default until standalone default-on graduation](flow_control_opt_in_feature_gate_posture.md) - Flow control ships with GA code maturity while remaining gated off by default so baseline deployments incur zero queueing change without explicit opt-in.
* [Opt-in backend request priority rewrite via PriorityRewriter interface](opt_in_backend_priority_rewrite.md) - Overwriting or stripping client-supplied priority fields on forwarded backend payloads requires explicit opt-in configuration through PriorityRewriter.
* [Once-per-request operational logs use V(logging.DEFAULT)](once_per_request_logs_default_verbosity.md) - Once-per-request operational log entries use logger.V(logging.DEFAULT).Info rather than bare logger.Info.
* [GitHub CI checks are the source of truth for commit requirements](github_ci_commit_requirements_source_of_truth.md) - Enforced GitHub CI workflows define commit sign-off and formatting requirements rather than duplicate prose rules in contributor docs.
* [make presubmit runs unit tests](make_presubmit_runs_unit_tests.md) - The top-level make presubmit target includes unit test execution so local pre-merge verification covers behavioral regressions alongside static lints.
* [Plugin graduation path across Alpha, Beta, and Stable tiers](plugin_graduation_tiers.md) - Every new plugin starts at Alpha with no compatibility guarantee, graduates to Beta with two-minor-version compatibility, and reaches Stable with within-major compatibility.
* [Pull request template distinguishes Fixes from Part of](pr_template_fixes_vs_part_of.md) - The pull request template distinguishes auto-closing Fixes references for complete resolutions from non-closing Part of references for multi-PR work.
