The deprecated UDS tokenizer backend and the indexer's in-process tokenization pool are removed. A configuration that sets `udsTokenizerConfig` on `token-producer`, or `indexerConfig.tokenizersPoolConfig` on `precise-prefix-cache-producer` or `precise-prefix-cache-scorer`, fails at startup with an unknown-field error naming the parameter. Remove the parameter from every plugin that sets it: `precise-prefix-cache-scorer` ignores its own parameters when a `precise-prefix-cache-producer` is also configured, so a stale value there is not always reported. For tokenization, set `vllm.url` on a `token-producer` to select the vLLM HTTP /render backend; the precise prefix cache takes its tokens from that plugin.
