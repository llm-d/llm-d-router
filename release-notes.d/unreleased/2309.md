The `inflight-load-producer` scheduler plugin now estimates a request's output tokens from an output-length class (LONG/UNKNOWN/SHORT) published by the new opt-in `outlen-bucket` plugin, replacing the fixed input-length ratio; enable `outlen-bucket` in the `plugins` list to use it.
