Coordinator now exposes Prometheus metrics on a dedicated /metrics endpoint (default port 9090, configurable via --metrics-port or server.metrics_port). Metrics cover request rate/latency/error mix, per-pipeline-step wall time and error classification, per-upstream call counts and latencies, execution path (decode-only / prefill-decode / encode-prefill-decode), conditional-decode probe outcomes, and render-derived input token count. Every model_name label is capped at 1000 distinct values with an "other" overflow.
