Flow control dispatch cost no longer scales with the number of registered flows: fairness policies scan only non empty queues, removing a per-dispatch allocation proportional to flow count. Action required for the `program-aware-fairness` plugin: the `lasDecayFactor` parameter is removed and a config that still sets it will fail startup. Attained-service decay is now wall-clock based and parameterized solely by `lasHalfLifeSeconds` (default 60, `0` disables decay); decay no longer pauses while requests are in flight. Action required for out-of-tree fairness policies: `PriorityBandAccessor.IterateQueues` now visits only non-empty queues. A policy that relied on a callback for every registered queue, for example to age per-flow state, must drive that work from elapsed time.
