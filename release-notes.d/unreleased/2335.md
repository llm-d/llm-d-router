The conditional-decode 412 gate (RFC 7240 `Prefer: if-available`) is now enforced by the `prefix-based-pd-decider` plugin instead of a hard-coded director check. Deployments that declare the plugin enforce the gate at the configured `nonCachedTokens` threshold (unweighted cached-block count) and honor its `promptTokens` short-prompt bypass. Deployments without a gate plugin fall back to a director-side default-deny: any `Prefer: if-available` request that no PreRequest plugin claimed is rejected with 412 (`conditional-decode request received but no gate plugin is configured`), surfacing a missing gate plugin as a fast fallback rather than a silent forward. To restore the previous "any weighted cache hit lets it through" behavior, set `nonCachedTokens: 1`.
