All requestcontrol extension points (RequestHeader, Screener, Admission, DataProducer, PreRequest, ResponseReceived, ResponseStreaming) now execute in the order computed from the plugins' Produces/Consumes declarations, so hook execution order no longer varies between EPP restarts. Plugins that declare neither run after the ordered ones, in name order.
