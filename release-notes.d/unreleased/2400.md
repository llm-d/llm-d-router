BREAKING: `kv_cache_index_lookup_hits_total` and `kv_cache_index_max_pod_hit_count_total` now report the longest contiguous prefix chain held by a single pod, counted from the first requested block. They previously counted every matching block regardless of contiguity, which overstated the cache hit a request could actually use. Dashboards and alerts on these metrics need to be re-baselined.
