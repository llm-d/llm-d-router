- Removed the deprecated `pd-profile-handler` plugin; use `disagg-profile-handler`. - Removed the deprecated `llm_d_inference_scheduler_pd_decision_total` metric; use `llm_d_epp_pd_decision_total`. - Removed the deprecated `"both"` value for the `llm-d.ai/role` pod label; use `"prefill-decode"` instead. Pods labeled `both` no longer match the decode/prefill filters. - Removed `disagg-profile-handler`'s deprecated flat parameter format (`decodeProfile`, `prefillProfile`, `encodeProfile`, `deciderPluginName`, `prefillDeciderPluginName`, `encodeDeciderPluginName`); use the nested `profiles`/`deciders` format.
