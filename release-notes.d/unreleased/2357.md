Coordinator now forwards requests for unregistered paths (e.g. /v1/models, /v1/messages, /v1/responses, /v1/embeddings) directly to a decode pod via EPP-Profile: decode, so clients no longer need to bypass the coordinator to reach these vLLM endpoints. Enforce server.max_request_body_size on passthrough (unregistered) paths; oversize requests now return 413.
